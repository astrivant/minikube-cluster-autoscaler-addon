# Security

This addon can create and delete nodes in its configured local cluster. Use a
dedicated lab, private journals, trusted host networking and explicit resource
ceilings. Mutual TLS authenticates clients but does not make a publicly exposed
host interface appropriate. Do not share the state directory or signing keys.

Report vulnerabilities privately through the repository's GitHub security
advisories when available. Do not post credentials or journals in public issues.
Maintainers should enable private vulnerability reporting when creating the
repository. No production support or long-term release support is promised yet.
